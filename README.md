# 波段作战台

面向 A 股投资小白的短线辅助工具。只做一种风格：**T+1 到 3～5 日波段**。不打板，不日内交易，不接券商实盘。

它要解决的是纪律，不是「荐股」，更不是保证收益。每笔纸上交易都必须带入场理由、仓位上限、止损、目标和持有天数。页面写明 **不是投资建议**，也不会出现必胜、胜率榜或保证收益的说法。

## 这一刀有什么

1. **今日候选**（最多 5 只）：先扫沪深 A 股公开快照（北交所、B 股不要），再对**本地日K库**过硬规则；用人话写放入选原因、结构类型、盈亏比，以及什么情况下作废。
2. **交易计划卡**：买多少（默认单票不超过总资金 20%，即 2 万元）、亏多少走、目标在哪、最多拿几天。
3. **模拟持仓与复盘**：纸上开平仓，受 T+1、最多 3 只、现金缓冲约束；公开延迟行情下浮盈按日K收盘计价。

演示资金 **10 万元**。同时持有不超过 3 只，股票占用最多约 6 万，至少留 4 万现金。

## 硬规则在挡什么

真正生效的规则在 `src/lib/scan-rules.ts`。它们用来少做错结构，**不会**把胜率变成一个可承诺的数字：

- 先扫沪深A股全市场快照（优先 AKShare 的腾讯快照，带量比），再对本地日K库里的票过硬规则
- 一手不超过 2 万；ST、涨停、一字板不要
- 量比 1.2～2.8，爆量高潮不要
- 收盘站上 5 日和 10 日线，且 5 日线不低于 10 日线
- 离开 10 日线：主板不超过 6%，创业板/科创板不超过 8%
- 当日涨幅小于 5%，连涨不超过 2 天；高开超过 4% 当追空处理
- 收盘要落在当日区间上半，长上影、振幅过大不要
- 近 10 日高点要有空间；止损不超过 6%，盈亏比至少 1.3
- 日K来自本地库；未入库不是结构不合格。盘中扫描不批量打公开源
- 最多 5 只，按结构排序，不是谁量最大谁上榜

规则变严之后，空仓会更常见。空仓也是计划。

## 本地日K库（库齐再扫）

公开源不能无节制狂拉。做法是：**先限速把约五千只日K铺进本机 SQLite，盘中扫描只读库**。

```bash
python3 -m pip install -r requirements.txt
npm install
# 可挂机、可 Ctrl+C 后续跑；腾讯/新浪分片，每源低并发+抖动间隔+失败退避
npm run kline:warm
# 试跑前 30 只：
npm run kline:warm -- --limit 30
```

- 库文件：`data/kline.sqlite`（已 gitignore）
- 进度：`http://127.0.0.1:43127/api/kline-cache`
- 单票调试仍可用 `/api/kline?code=000001`
- 若某源熔断：先停，过会儿再续跑；**不要加大并发硬刚**
- 首次铺库可能要数小时；宁慢勿封

盘中 `/api/desk` 只读本地库过硬规则，不会为了补齐库去打五千次上游。

## 本地运行

需要 Node.js 20+。全市场快照优先走 AKShare（封装腾讯行情，带量比）。没装 Python 依赖时，仍会退回东方财富/新浪列表。

```bash
python3 -m pip install -r requirements.txt
npm install
npm run kline:warm -- --limit 50   # 先小跑验证
npm run dev
```

浏览器打开 [http://127.0.0.1:43127](http://127.0.0.1:43127)。开发服务器默认绑在 `0.0.0.0:43127`。

```bash
npm run build
npm start
```

纸上账户存在浏览器 `localStorage`，用「重置账户」可以回到 10 万空仓。

## 本机仍显示离线演示时

1. `git pull` 后 **停掉再开** `npm run dev`。
2. 先确认日K库：`/api/kline-cache` 里 `coverage.ok` 是否在涨；没有库时先 `npm run kline:warm`。
3. 单票：`/api/kline?code=000001` 应是 JSON。
4. 页面右上角不要停在「离线演示」。
